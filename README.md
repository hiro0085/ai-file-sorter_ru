**AI File Sorter RU** — русифицированная сборка AI File Sorter для Windows. Программа анализирует файлы с помощью локальной или удаленной AI-модели, предлагает понятные категории и помогает разложить хаотичные папки по структуре.

Эта версия подготовлена для русскоязычных пользователей: переведен интерфейс, категории, основные статусы анализа и тексты, которые чаще всего видны при работе.

## Возможности

- Автоматическая сортировка файлов по смысловым категориям.
- Работа с локальными AI-моделями через llama.cpp.
- Поддержка удаленных OpenAI-совместимых API.
- Анализ изображений, документов, аудио и видео.
- Предварительный просмотр результата перед переносом файлов.
- Настройка категорий и правил сортировки.
- Проверка совместимости системы перед запуском локальной модели.
- Портативный режим без классической установки.

## Как пользоваться

1. Скачайте `AIFileSorter-ru-single.exe` из раздела релизов.
2. Запустите файл.
3. Выберите папку с файлами, которые нужно разобрать.
4. Выберите режим AI-модели: локальная модель или удаленный API.
5. Запустите анализ.
6. Проверьте предложенные категории.
7. Подтвердите сортировку.

## Как это работает

Приложение собирает доступную информацию о файле: имя, расширение, метаданные и, если включено, содержимое документа или изображения. Затем AI-модель определяет наиболее подходящую категорию. После анализа можно просмотреть результат и только потом переместить файлы.

По умолчанию приложение не отправляет файлы в интернет, если вы используете локальную модель. При выборе удаленного API данные передаются выбранному вами провайдеру.

## Локальная модель

Локальный режим подходит, если нужно сохранить приватность и не зависеть от облачных сервисов. Приложение использует llama.cpp и может работать с GGUF-моделями.

Плюсы локального режима:

- файлы не покидают ваш компьютер;
- нет платы за API-запросы;
- можно работать без постоянного подключения к интернету после загрузки модели.

Минусы:

- скорость зависит от процессора, видеокарты и объема памяти;
- крупные модели требуют больше ресурсов;
- качество результата зависит от выбранной модели.

## Удаленный API

Удаленный режим подходит, если нужен более быстрый или качественный анализ без настройки локальной модели. Поддерживаются OpenAI-совместимые API.

Перед использованием удаленного режима проверьте настройки приватности и условия выбранного провайдера, потому что часть данных о файлах может передаваться наружу.

## Категории

AI File Sorter RU умеет предлагать категории на русском языке. Например:

- Изображения
- Видео

- Архивы

- Проекты
- Финансы
- Работа
- Личное
- Другое

Категории можно адаптировать под собственный стиль сортировки.

## Анализ изображений

Для изображений приложение может учитывать визуальное содержимое, а не только имя файла. Это помогает отличать скриншоты, фотографии, документы, мемы, иллюстрации и другие типы изображений.

## Анализ документов

Для документов приложение может использовать текстовое содержимое и метаданные. Это полезно для PDF, офисных файлов, заметок, отчетов, инструкций и других текстовых материалов.

## Аудио и видео

Для медиафайлов программа использует имя файла, расширение и доступные метаданные. Это помогает отделять музыку, записи, клипы, фильмы, уроки, рабочие материалы и прочие медиа.

## Совместимость

Русская сборка ориентирована на Windows. Готовый exe-файл сделан для удобного запуска без самостоятельной сборки проекта.

Основные требования:

- Windows 10 или Windows 11;
- 64-разрядная система;
- достаточно свободного места для временной распаковки приложения;
- для локальных моделей — достаточно оперативной памяти под выбранную модель.
